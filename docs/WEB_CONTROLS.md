# 网页操作中心

打开 http://127.0.0.1:8080/#control-center 。管理操作共用「合约账户与持仓」的本机密码解锁，密码可通过根目录「FreqUI登录信息.cmd」查看。网页会话过期不会停止独立后台。

## 可直接使用的操作

- 行情控制：BTC/USDT、ETH/USDT、SOL/USDT；合约优先 / 仅合约 / 仅现货参考；3、5、10、30 秒采集间隔；立即采集、暂停、恢复。点击「应用设置」后写入 SQLite，重启保留。暂停时在途请求会结束，但旧请求不能覆盖新配置；恢复后重新采集。
- 图表：放大、缩小、查看前面的 K 线、回到最新；悬停查看 OHLC。改变图表视图不改变后台采集设置。
- 日志：按级别、关键词筛选最近 120 条记录，导出当前筛选结果为 CSV。
- 网络诊断：从实际 WSL / 容器运行环境检测两个固定币安公共端点，返回成功与否和耗时。30 秒内复用结果，不传送密钥。网络通不等于账户认证通过。
- 开始数据分析：对本地最多 120 根已收盘 K 线做描述统计（区间涨跌、高低价、20 根均值、成交量），需至少 20 根。统计记录在 SQLite 保留最近约 100 次。显示来源和数据截止时间；不预测、不调用 AI、不产生订单。

## API 配置及启动入口

「API 配置」提供币安 Key / Secret 配置入口，以及 DeepSeek Key、模型 ID、月预算的填写与清除。两者都在本机加密保存，不向浏览器回显。DeepSeek 目前仅保存配置，未验证远程 Key，不发起付费调用；预算为待验收配置值，不表示硬限额系统已完成。

「分析与交易」包含数据分析、AI 研究、模型训练、模拟交易、实盘授权与启动、停止入口。

行情数据描述统计和手动 AI 研究已实现执行链路。AI 研究需要通过密钥/模型验证、预算及服务状态检查，详见 [AI 研究与费用控制](AI_RESEARCH.md)。训练、模拟和实盘仍返回 409 并列出阻塞条件，不能绕过网页直接启用。实盘授权流程尚未接通；不记录或伪造用户实盘授权。

当前模拟未运行，实盘始终禁止；下一阶段必须完成执行器、独立风控、订单去重和恢复、验收及人工授权，才可开放真实交易。页面上的入口不代表这些后端能力已经实现。

## 状态解释

- 「用户已暂停采集」：主动暂停导致的旧行情，与网络断线不同；到行情控制点击「恢复采集」。
- 「网络未更新 · 行情过期」：后台超过新鲜度窗口未取得新数据。默认窗口 30 秒；采集间隔设为 30 秒时窗口自动放宽到 65 秒，避免正常轮询被误报。查看服务心跳并执行连接诊断。
- 「现货参考行情」：当前显示的是现货数据，不能当作合约成交价。仅合约模式不会自动回退。
