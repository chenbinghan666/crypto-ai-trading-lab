# 手动 AI 研究与费用控制

2026-10-16 更新。官方 TradingAgents 0.6.0 的多角色研究工作流已接入网页、独立进程、费用闸门与报告展示。仍不启动训练、回测、模拟或真实交易。

## 网页使用

1. 在「合约账户与持仓」解锁本机管理面板。
2. 「操作中心 → API 配置」保存 DeepSeek Key、模型 ID 和月预算，再点击「验证 DeepSeek 连接（不生成内容）」。只向固定 `https://api.deepseek.com/models` 发送 GET；不会生成内容，不代表已验证余额。
3. 「操作中心 → 分析与交易」查看 AI 研究是否可运行。点击「开始 AI 研究（≤¥0.50）」才创建付费研究任务；保存密钥和打开网页均不会自动发起研究。
4. 同一页面查看任务排队、执行进度、已记账/预留费用、市场分析、多空汇总、交易员意见及最终风险讨论。点击该模块的「停止」请求终止任务。

本机当前配置的 `deepseek-v4-pro` 已通过真实模型列表认证。用户手动保存的月预算为 50 元；程序按保存配置执行，不擅自更换模型或提高预算。尚未执行首个真实付费研究；远程推理及余额是否充足需在用户手动发起后验证。

## 数据和角色边界

使用发起时冻结的本机公开行情：最多 120 根已收盘 1 分钟 K 线的描述统计及最后 24 根 K 线。需要未过期行情和至少 20 根已收盘数据。来源、市场类型和截止时间写入任务及报告。

市场分析节点适配本机加密资产数据，替换默认股票工具；后续看多/看空研究员、研究经理、交易员、风险讨论与组合经理沿用实际 TradingAgents 工作流。不会隐式调用股票基本面、新闻或 Yahoo 数据。没有接入新闻、资金费率或长期样本时，在上下文明确标记缺失。

若当前数据是「现货参考」，研究报告也按现货参考解读；不冒充永续合约数据。约两小时样本的研究不是经过验证的策略，也不构成回测。结果固定标记 `research_only=true`、`trading_eligible=false`；不进入 Freqtrade 执行器，不生成订单。

## 费用闸门

- 月预算来自本机网页配置；每日 1 元；单次研究总额上限 0.5 元；最多 16 次推理请求。
- 一次只运行一个任务；新任务间隔至少 5 分钟。模型调用输出限制 512 tokens，禁用推理扩展思考，SDK 自动重试为 0；任务最长 180 秒。
- 每个推理请求先在 SQLite 原子预留保守费用，收到真实 `usage` 后按输入/输出/缓存用量结算。相同请求 ID 不得重复发送。
- 超时、未知结果或进程中断保留费用预留，避免以“失败”为由释放额度、重复扣费。不会自动重发中断的付费任务。停止任务无法撤回已经送达供应商的请求。
- 价格取自 DeepSeek 官方页的高峰价格，2026-10-16 核验；Flash 每百万输入未缓存 2 元、缓存 0.04 元、输出 8 元；Pro 分别 9、0.30、27 元。价格核验有效期至 2026-10-23，过期拒绝新增调用。来源：https://api-docs.deepseek.com/zh-cn/quick_start/pricing/ 。
- 费用显示为保守估算，服务商账单为准。这里只控制本系统发出的请求，不能管理同一 Key 在其他程序中的消费；价格变更与供应商计量可能使账单不同。

真实 Key 仅在本机加密存储及固定 DeepSeek HTTPS 发送端使用。TradingAgents SDK 接收一次性本机网关令牌，不能直接获得真实 Key。网关仅监听随机回环端口，禁止重定向转发凭据。真实密钥、请求头和原始异常不会写入应用日志或报告。

## 独立运行和恢复

研究服务由现有 Windows / Docker 守护维护，网页只负责发起和查看任务。关闭网页或 Codex 不会取消任务。研究进程与服务父进程绑定，服务退出时终止子进程；恢复时把原运行任务标记为 interrupted，人工检查后再发起新任务。过期的排队任务不自动执行。

状态、报告索引和费用记录位于 `data/system/system.sqlite`；完整 Markdown 报告位于 `data/system/tradingagents/jobs/<id>/reports/`。其中不保存交易所账号资金信息。

## 验证范围

- 48 项自动化测试通过，覆盖认证结果失效、无价格/过期价格拦截、并发预算、重复请求、未知费用、任务去重、恢复和请求 token 上限。
- 在独立临时环境，运行真实 TradingAgents 工作流，通过本机网关返回模拟模型响应，完成 9 次角色推理和报告生成；对外 DNS / TCP 均被测试阻止。测试费用账本不是用户真实消费记录。
- 证据：`reports/evidence/phase3/research_pipeline_offline.json`。这证明集成链路可执行，不代表付费模型结果或盈利已经验证。
- 当前训练、模拟执行、订单恢复、研究信号到 Freqtrade 的桥接仍未完成；实盘保持禁止。
