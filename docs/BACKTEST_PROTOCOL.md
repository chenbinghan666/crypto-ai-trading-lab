# 回测协议

先确定可获取数据与区间，存 UTC、来源、下载时刻、市场、缺失/重复检测和文件哈希。只用已收盘 K 线，指标预热与标签未来窗口分离。

按时间拆分训练/验证/锁定测试集，Walk-forward，边界排除跨越未来标签区间的数据。测试集不反复调参。比较趋势、均值回归、突破、FreqAI 和经适配验证的 Agent/融合策略，加入持有 BTC 与不交易基线；统一时间区间和资金/成本假设。

扣除手续费、滑点、点差、适用资金费率及 API 成本；部署成本另列经济性。记录完整交易数、订单数、持仓时长、净收益、Profit Factor、回撤、Sharpe/Sortino（样本足够才计算）、换手率和成本比例。覆盖上涨/下跌/震荡/高波动；lookahead-analysis、敏感性分析和消融实验列入验收。没有真实研究记录时不能把现代 Agent 输出回填历史行情声称无前视。

输出数据哈希、代码提交、依赖/镜像版本、参数、随机种子和运行命令。阶段 1 没有收益结果。
