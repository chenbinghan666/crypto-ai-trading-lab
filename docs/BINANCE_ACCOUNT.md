# 币安 U 本位合约账户与实时界面

当前阶段只读查看账户，不运行模拟交易或真实交易。FreqUI 继续使用独立的公共行情配置，不接收账户密钥。本功能不是交易执行器，也没有完成未来实盘的风控验收。

## 使用

1. 双击「启动系统.cmd」，访问 http://127.0.0.1:8080/ 。不要直接打开 HTML 文件预览。
2. 双击「FreqUI登录信息.cmd」，使用显示的管理密码解锁「合约账户与持仓」。这是本机管理密码，不是币安登录密码。
3. 在本机页面输入 Binance HMAC API Key / Secret，点击「保存并验证只读连接」。不要在聊天中发送密钥。本版本不支持 RSA / Ed25519 密钥。
4. 页面显示「只读连接正常」及成功同步时间后，才能认为账户连接成功。保存成功仅代表本机已保存密钥，不代表币安验证通过。
5. 「锁定面板」退出本机浏览器会话，后台同步继续；「解除绑定」删除本机加密密钥、清除内存快照并停止后续查询，不会撤销币安网站上的 API Key。

仅需要账户读取权限，不需要交易、提币或划转权限。币安账户须具备相应合约产品访问资格；权限或地区限制不会被绕过。

## 数据范围

- U 本位合约钱包余额、保证金余额、可用余额、未实现盈亏。
- 持仓合约、多空方向、数量、开仓均价、标记价格、强平价格、未实现盈亏及保证金资产。双向持仓分别展示。
- 非零合约资产余额；不合并现货、币本位、资金账户、理财或统一账户专用接口的数据。
- 汇总字段采用币安原始定义：单资产模式为 USDT，多资产模式为 USD。逐资产字段按原币计价。
- 未实现盈亏不等于已实现收益或系统收益；不生成虚假的累计收益。

服务每 30 秒查询一次账户，页面每 3 秒读取本机缓存，多开浏览器不会增加币安查询频率。此版本是 REST 轮询，不是账户 WebSocket 推送。失败保留上次快照并显示异常，超过 65 秒标记过期；重启后重新查询，不把旧余额作为最新数据恢复。

公开行情优先使用 U 本位合约 `fapi.binance.com`。合约时间接口不可用时，明确切换为 `data-api.binance.vision` 的**现货参考行情**，不会把现货价格标成合约价格。切换来源时清除该图旧来源的 K 线，避免混合。每 60 秒重新尝试合约接口。公共行情目标采集间隔 3 秒（另加请求耗时），界面每 1 秒读取本机缓存。

K 线默认显示最近 15 根 1 分钟蜡烛，可切换 30 分钟 / 1 小时 / 2 小时。纵轴按可见价格范围自动缩放，并显示实际区间振幅；这是观察窗口缩放，不是收益放大。末根半透明蜡烛为未收盘行情，不写入已收盘历史。

## 本地安全与部署

- 管理会话为 HttpOnly、SameSite=Strict Cookie，1 小时过期。重启服务使旧会话失效。
- 所有账户写配置请求检查同源 Origin；未登录无法读取账户数据。公共 `/api/status` 不含账户余额或密钥。
- 账户客户端只允许向 `https://fapi.binance.com` 发出三个固定 GET 请求：`/fapi/v1/time`、`/fapi/v3/account`、`/fapi/v3/positionRisk`。禁止重定向转发凭据，没有订单、撤单、杠杆或划转接口。
- 默认 WSL 密钥目录：`~/.local/share/crypto-ai-trading-lab/secrets`。`vault.key` 是本机加密钥，`binance.enc` 是加密凭据；目录 700，文件 600。不要提交、发送或公开这两个文件。本机同一操作系统用户仍可访问解密材料，加密不防御已被入侵的主机。
- Docker 目录由 `LAB_SECRETS_DIR=/app/data/system/private` 指定，位于持久数据卷。该配置已提供，尚未在本机实际运行 Docker 验证。
- 仅绑定回环端口。未来迁移 VPS 优先通过 SSH 隧道访问，不要直接公开 8080/8081；互联网访问必须单独完成 HTTPS 和访问控制部署。

## 故障恢复

- `fapi.binance.com` DNS / 网络错误：在实际运行的 WSL 或容器中检查域名解析和 HTTPS 可达性。当前开发环境确实遇到此问题，因此尚未完成真实账户联调。不要将私有 API 密钥改发到公共行情域名。
- 认证失败：检查 HMAC Key/Secret 配对、读取权限、IP 白名单及本机时间。服务使用币安服务器时间签名；错误日志不记录签名 URL 或密钥。
- 429 / 418：后台退避 5 分钟，前端显示等待时间，不要反复重新绑定。
- 解密失败：解锁面板，解除绑定，再输入新的有效密钥。备份恢复需要密文和对应加密钥；不保留加密钥的迁移应重新绑定。
- 服务重启：一键脚本的独立守护继续拉起管理服务；账户查询线程随管理服务启动并从加密凭据恢复。浏览器需要重新解锁。

## 已验证与待验证

自动化测试覆盖：未登录拒绝、同源保护、会话到期、登录限流、密钥加密与不回显、固定 GET 签名与路径白名单、禁止重定向、双向持仓映射、断线快照、限流退避、解除绑定时阻止在途请求回写。

浏览器验证：本机密码解锁、账户未绑定状态、K 线窗口切换与倒计时。没有填入真实币安 API Key，没有发出任何交易或模拟订单。真实账户余额正确性、币安权限和网络连通性，待用户在本机绑定后验证。
