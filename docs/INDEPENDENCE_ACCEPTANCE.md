## 关闭 Codex 后的基础设施验收

1. 双击 `启动系统.cmd`，在普通 Edge/Chrome 打开 http://127.0.0.1:8080 。
2. 完全退出 Codex，不关闭 Windows 或休眠。
3. 双击 `验证独立运行.cmd`，执行 30 秒只读行情和健康验证。
4. 查看 `reports/evidence/phase2/system_acceptance.json`。
5. 停止/重启服务，核对数据与事件历史保留。

检查脚本可以证明数据持续更新，不能自行证明桌面应用完全退出，所以明确记录 `codex_application_closed=not_observable_by_this_script`。不冒称已经替用户完成关掉 Codex 的人工操作。

后续在独立服务中实现并验收 DeepSeek 真实小额调用、FreqAI 训练、完整风控和模拟订单账本，再进行关闭开发工具后的长时全流程验收。实盘必须再独立审核和人工授权。
