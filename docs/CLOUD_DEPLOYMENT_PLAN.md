# 云端迁移设计（不采购、不部署）

本地 Windows 用于开发和首次模拟验证，未来将相同 Compose、环境变量和相对数据卷迁往常开 Linux VPS，无 GPU 需求。个人电脑关机后只有云上实际部署的服务才能持续运行；当前没有后台服务。

| 方案 | 初始规划资源，须实测 | 特点 |
|---|---|---|
| 云执行 + 本地离线训练 | 2 vCPU / 4 GiB RAM / 40–80 GiB SSD | 云端只预测和模拟执行，本地关机不影响已有模型；训练更新需校验版本后上传 |
| 全云 CPU 训练与执行 | 4 vCPU / 8 GiB RAM / 80 GiB SSD 起 | 简化调度，训练需单并发和限额，资源不足再评估 |

成本采用规划情景而非厂商报价：服务器若每月 RMB 50/100/200，加 API 上限 30，合计 80/130/230，未含备份、税费与流量。分别约为 RMB 200 初始模拟本金的 40%/65%/115%；固定费用可能远超策略收益。采购前按地区、可用性和正式报价重新核验，不预设供应商。

迁移步骤：固定镜像 digest → 配置最小权限用户与私有管理访问 → 创建模拟专用持久卷 → 恢复账本/已验证模型 → 检查时间与数据新鲜度 → 核对订单 → 模拟运行及故障演练 → 再评审。禁止复制真实交易凭证或自动开启 live。

每日数据库一致性备份，保留 7 个日备份和 4 个周备份作为初始方案；密钥另行加密管理。日志轮转、磁盘/内存监测、健康检查、有限自动重启；重启不等于恢复可开仓。告警通道待选择，远程查看先经 SSH 隧道，不开放管理端口到公网。

更新前备份并停止新仓，模拟验证新版，保留旧镜像/模型和数据库恢复方案。演练断网、进程退出、磁盘满、重启和备份恢复。VPS 不能保证 100% 在线。
